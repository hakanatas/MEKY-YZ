# Gençler YZ Öğreniyor

**Minik Eller Kod Yazıyor** projesinin (2019–2026) yeni dönemi için hazırlanan interaktif sunum sitesi.
Hedef kitle: ortaokul (5–8. sınıf, 10–14 yaş).

- `index.html` — tek dosyalık, bağımlılıksız site. Tarayıcıda açmak yeterli (Google Fonts dışında dış kaynak yok).
- Kaydırarak ilerleyen 13 bölüm; her bölümde öğrencinin kendisinin deneyebileceği bir araç var:
  dönüşüm kaydırıcısı, "YZ mi değil mi?" testi, örneklerden öğrenen karar haritası, prompt atölyesi,
  "paylaşır mısın?" kartları, halüsinasyon dedektifi, hikâye makinesi, kural/öğrenen sohbet botu,
  etik ikilem kartları, trafik ışığı, görev paylaşımı, program taslağı ve YZ okuryazarı sözü.

## Yayınlama

Statik bir dosya olduğu için GitHub Pages, Netlify ya da herhangi bir web sunucusuna `index.html` olarak yüklenebilir.
