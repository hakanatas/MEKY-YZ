# Logolar

Bu klasöre şu iki dosyayı koyun; footer otomatik olarak gösterir (dosya yoksa yazı logosu görünür):

- `qnb-logo.png` — QNB logosu (basın odası: qnb.com.tr › QNB'yi Tanıyın › Basın Odası › Logolar). Tercihen şeffaf arka planlı, yatay sürüm.
- `habitat-logo.png` — Habitat Derneği yatay logosu (Drive'daki `habitat-yatay-logo.png`).

Önerilen boyut: yükseklik en az 120 px, PNG veya SVG (SVG için `index.html` içindeki `src` uzantısını değiştirin).
